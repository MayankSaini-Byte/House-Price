R² Score Comparison

R² (coefficient of determination) measures how much variance in house prices the model explains. A score of 1.0 means perfect prediction. Higher is better.

Linear Regression

{% if results.get('Linear Regression', {}).get('r2', 0) == results.values()|map(attribute='r2')|max %} Best Model {% endif %}

Theory

Linear Regression finds a linear relationship between input features and the target. It fits a straight line (or hyperplane in multiple dimensions) that minimizes the sum of squared differences between predicted and actual values.

The model assumes that house price is a weighted sum of all features: Price = w₁×Area + w₂×Quality + w₃×Age + ... + bias

Mathematical Intuition

The model minimizes the Ordinary Least Squares (OLS) cost function:

J(w) = Σ(yᵢ − ŷᵢ)² = Σ(yᵢ − wᵀxᵢ)²

The closed-form solution is w = (XᵀX)⁻¹Xᵀy. Each weight wⱼ represents how much the price changes per unit increase in feature j, holding all other features constant. This is why scaling features is important — without it, features with larger scales would appear more important.

Advantages

  • Fast training — closed-form solution, no iteration needed
  • Highly interpretable — each coefficient has a clear meaning
  • No hyperparameters to tune
  • Works well when features have linear relationships with target
  • Low risk of overfitting with proper regularization

Disadvantages

  • Cannot capture non-linear relationships without feature engineering
  • Sensitive to multicollinearity
  • Assumes homoscedasticity (constant variance of errors)
  • Sensitive to outliers — squared errors amplify outlier influence

Implementation

Python 
from sklearn.linear_model import LinearRegression

# Initialize — no hyperparameters needed
lr = LinearRegression()

# Train on scaled features
lr.fit(X_train_scaled, y_train)

# Predict on test set
y_pred = lr.predict(X_test_scaled)

# Evaluate
print(f"R² Score: {r2_score(y_test, y_pred):.4f}")
Why Linear Regression Performs Best Here

Our extensive feature engineering (TotalSF, OverallScore, HouseAge) explicitly creates the non-linear interactions that linear models can't learn on their own. The log transformation of SalePrice also linearizes the relationship between features and price. Combined with StandardScaler normalization, this gives Linear Regression an ideal setup. The model sees the problem as: log(price) ≈ linear combination of well-engineered features, which is exactly what it's designed to solve.

Random Forest Regressor

Ensemble Model

Theory

Random Forest is an ensemble method that builds many decision trees on random subsets of the data and averages their predictions. Each tree sees a different random sample (bagging) and a random subset of features at each split.

The "wisdom of crowds" effect reduces overfitting — individual trees may overfit, but averaging many diverse trees produces a robust, generalizable prediction.

Mathematical Intuition

Final prediction is the average of all tree predictions:

ŷ = (1/N) × Σ Treeᵢ(x)

Each tree recursively splits the data on the feature/threshold that maximizes variance reduction (minimizes MSE within each leaf). The randomization in feature selection at each split decorrelates the trees, reducing the variance of the ensemble.

Implementation & Hyperparameters

Python 
from sklearn.ensemble import RandomForestRegressor

rf = RandomForestRegressor(
    n_estimators=100,    # Number of trees in the forest
    random_state=42,    # Reproducibility seed
)

rf.fit(X_train_scaled, y_train)

Gradient Boosting Regressor

Advanced

Theory

Unlike Random Forest (which builds trees independently), Gradient Boosting builds trees sequentially. Each new tree tries to correct the errors (residuals) of all previous trees combined.

Think of it as iterative refinement: the first tree makes a rough prediction, the second tree focuses on what the first got wrong, the third fixes remaining errors, and so on.

Mathematical Intuition

At each step m, we fit a tree to the negative gradient of the loss:

Fₘ(x) = Fₘ₋₁(x) + η × hₘ(x)

Where η is the learning rate (controls step size) and hₘ(x) is the tree fitted to the residuals. Smaller learning rates require more trees but typically produce better generalization.

Implementation & Hyperparameters

Python 
from sklearn.ensemble import GradientBoostingRegressor

gb = GradientBoostingRegressor(
    n_estimators=200,     # Number of boosting stages
    learning_rate=0.1,    # Step size shrinkage
    max_depth=4,          # Maximum depth of individual trees
    random_state=42,
)

gb.fit(X_train_scaled, y_train)

Support Vector Regressor (SVR)

Kernel Method

Theory

SVR finds a function that deviates from the actual values by at most ε (epsilon) while being as flat as possible. Points within the ε-tube are not penalized; only points outside it contribute to the loss.

The RBF kernel maps data into a higher-dimensional space where non-linear relationships become linear, enabling SVR to capture complex patterns.

When to Use

SVR works best with small to medium datasets and when the relationship between features and target is complex. It struggles with very large datasets (O(n²) training complexity) and requires careful feature scaling. On this dataset, the limited iteration count constrains its performance.

Implementation

Python 
from sklearn.svm import SVR

svr = SVR(
    kernel='rbf',     # Radial Basis Function kernel
    C=1.0,            # Regularization parameter
    max_iter=5000,    # Maximum iterations for convergence
)

K-Nearest Neighbors Regressor

Instance-Based

Theory

KNN is the simplest ML algorithm: to predict the price of a new house, find the K most similar houses in the training data and average their prices. "Similarity" is measured by Euclidean distance in feature space. No model is actually trained — the algorithm stores the entire training set and queries it at prediction time.

Why It Underperforms Here

With 280+ features after one-hot encoding, the feature space is very high-dimensional. In high dimensions, all points become roughly equidistant (the "curse of dimensionality"), making distance-based similarity meaningless. KNN works best with few, carefully selected features.

Implementation

Python 
from sklearn.neighbors import KNeighborsRegressor

knn = KNeighborsRegressor(
    n_neighbors=5,    # Number of neighbors to average
)
