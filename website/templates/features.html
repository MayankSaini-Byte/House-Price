Feature Engineering

Crafting new features from existing data to give the model richer signals about what makes a property valuable. Each feature is driven by real-estate domain knowledge.

HouseAge
Formula
HouseAge = YrSold − YearBuilt
Python Code
train['HouseAge'] = train['YrSold'] - train['YearBuilt']
Business Intuition

Buyers care about how old a house is, not the absolute year it was built. A house built in 1960 and sold in 2008 (48 years old) is different from one built in 2005 and sold in 2008 (3 years old). Age captures depreciation and wear.

Why It Improves Prediction

The raw year is a large number (e.g., 1985) that doesn't linearly relate to price. Age (e.g., 23 years) directly measures depreciation, which has a much cleaner negative correlation with sale price.

RemodAge
Formula
RemodAge = YrSold − YearRemodAdd
Python Code
train['RemodAge'] = train['YrSold'] - train['YearRemodAdd']
Business Intuition

A recently remodeled house commands a higher price than one that hasn't been updated since it was built. This captures how "fresh" the home feels to buyers, independent of its construction year.

Why It Improves Prediction

Renovation resets perceived age. A 50-year-old home remodeled 2 years ago behaves like a newer home in the market. RemodAge captures this economic reality.

TotalSF
Formula
TotalSF = GrLivArea + TotalBsmtSF
Python Code
train['TotalSF'] = train['GrLivArea'] + train['TotalBsmtSF']
Business Intuition

Buyers evaluate total usable space, not just above-ground vs. basement separately. A finished basement adds significant functional square footage that impacts value.

Why It Improves Prediction

Combining two correlated features into one reduces multicollinearity while preserving the total information. Models can learn a single coefficient for "total space" instead of balancing two correlated inputs.

TotalBath
Formula
TotalBath = FullBath + 0.5 × HalfBath + BsmtFullBath + 0.5 × BsmtHalfBath
Python Code
train['TotalBath'] = (
    train['FullBath'] +
    0.5 * train['HalfBath'] +
    train['BsmtFullBath'] +
    0.5 * train['BsmtHalfBath']
)
Business Intuition

Bathroom count is a key real-estate metric. A half bath counts as 0.5 because it has a toilet and sink but no shower/tub. This weighted sum matches how real-estate agents actually count bathrooms in listings.

Why It Improves Prediction

Consolidates 4 bathroom features into 1, reducing dimensionality while encoding real-world valuation logic. A 3.5-bath home is consistently worth more than a 2-bath home.

OverallScore
Formula
OverallScore = OverallQual × OverallCond
Python Code
train['OverallScore'] = train['OverallQual'] * train['OverallCond']
Business Intuition

A high-quality house in poor condition is worth less than a high-quality house in excellent condition. Multiplication captures this interaction: a 10-quality, 5-condition home (score=50) vs. a 10-quality, 9-condition home (score=90).

Why It Improves Prediction

Linear models can't learn feature interactions on their own — they treat OverallQual and OverallCond independently. This engineered interaction term gives the model the ability to capture their combined effect.

HasGarage
Formula
HasGarage = 1 if GarageArea > 0, else 0
Python Code
df['HasGarage'] = (df['GarageArea'] > 0).astype(int)
Business Intuition

The binary presence/absence of a garage is often more important than its exact size. Having any garage significantly impacts property value.

Why It Improves Prediction

Creates a clean signal the model can use as a threshold. Combined with GarageArea, the model can learn both "does it have a garage?" (binary) and "how big is it?" (continuous).

HasPool
Formula
HasPool = 1 if PoolArea > 0, else 0
Python Code
df['HasPool'] = (df['PoolArea'] > 0).astype(int)
Business Intuition

Pools are rare (only 7 out of 1,460 properties). Their presence signals a luxury property, which significantly impacts market positioning and price.

Why It Improves Prediction

With only 7 pool properties, the binary flag is more informative than the continuous PoolArea, which is 0 for 99.5% of rows. The flag acts as a luxury indicator.

HasBasement
Formula
HasBasement = 1 if TotalBsmtSF > 0, else 0
Python Code
df['HasBasement'] = (df['TotalBsmtSF'] > 0).astype(int)
Business Intuition

Basements add significant value through extra living/storage space. Their presence is a key differentiator, especially in the Midwest.

Why It Improves Prediction

Similar to HasGarage — the binary presence captures a step-change in value that continuous TotalBsmtSF alone might not cleanly represent at zero.

HasFireplace
Formula
HasFireplace = 1 if Fireplaces > 0, else 0
Python Code
df['HasFireplace'] = (df['Fireplaces'] > 0).astype(int)
Business Intuition

Fireplaces are a desirable amenity that signal comfort and character. Having at least one fireplace meaningfully increases perceived home value.

Why It Improves Prediction

The binary flag separates "no fireplace" from "has fireplace" more cleanly than the count, since the jump from 0→1 fireplace has a much larger price impact than 1→2.
