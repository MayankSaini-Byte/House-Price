How Machine Learning Learns House Prices

A beginner-friendly explanation of how a computer learns to predict house prices from data, without being explicitly programmed with pricing rules.

What are Features?

Features are the measurable properties of each house that we give to the model. Think of them as the information on a real-estate listing: square footage, number of bedrooms, year built, neighborhood, and so on.

In our dataset, we have 80 features — everything from lot size to the type of heating system. The model's job is to figure out which features matter most and how they combine to determine the price.

What is the Target Variable?

The target variable is what we're trying to predict — in our case, the SalePrice. During training, the model has access to both the features AND the sale price for each house. It uses this "answer key" to learn the relationship between features and price.

Key Concept

This is called supervised learning because the model is "supervised" by the known answers. It's like a student studying with an answer key — they see both the question (features) and the answer (price), and gradually learn the pattern.

The Training Process

Training is how the model learns. Here's what happens step by step:

1

Initialize Random Weights

The model starts with random guesses for how important each feature is. At this point, its predictions are essentially meaningless.

2

Make Predictions

Using its current weights, the model predicts the price for each training house. Initially, these predictions will be wildly inaccurate.

3

Calculate Error

The model compares its predictions to the actual sale prices. The difference is called the loss or error. A common measure is Mean Squared Error (MSE) — the average of all squared prediction errors.

4

Adjust Weights

The model adjusts its weights to reduce the error. For Linear Regression, there's a direct mathematical formula. For other models, this is done iteratively using gradient descent — moving weights in the direction that decreases error.

5

Repeat Until Convergence

Steps 2–4 repeat until the error stops decreasing significantly. At this point, the model has "learned" — its weights encode the relationship between features and prices.

Validation — Checking for Overfitting

We split the data into 80% training and 20% testing. The model only sees the training data during learning. The test data is held back to evaluate how well the model generalizes to houses it has never seen before.

Why Not Use All the Data?

If we test on the same data the model trained on, it could simply memorize the answers (overfitting). The held-out test set tells us if the model learned general patterns vs. just memorizing specific houses. Our best model achieves an R² of 0.90 on test data, meaning it explains 90% of price variation on houses it has never seen.

Making Predictions

Once trained, the model can predict the price of any new house. You provide the features (area, quality, age, etc.) and the model applies its learned weights to produce a price estimate.

For Linear Regression, this is simply multiplying each feature by its learned weight and summing:

Price = w₁ × LivingArea + w₂ × Quality + w₃ × Age + ... + bias

The model learned that living area has a positive weight (more area → higher price) and house age has a negative weight (older → lower price). These weights were automatically discovered from the data — we never told the model that bigger houses cost more.
